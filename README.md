# Amazon_products_sales_data_cleaning.
Amazon Products Sales Data Cleaning

Project Overview:

This project focuses on cleaning and preprocessing an uncleaned Amazon products sales dataset using Python. The goal is to improve data quality, handle inconsistencies, and prepare the dataset for further analysis and reporting.

Data cleaning is an important step in the data analytics process because reliable insights depend on accurate, consistent, and well-structured data.

Project Objectives:

Inspect the raw dataset and understand its structure.

Identify missing values and duplicate records.

Handle data quality issues and inconsistencies.

Standardize column names and data formats where required.

Validate the cleaned dataset.

Export the cleaned data for further analysis and visualization.

Tools and Technologies:

Python – Data cleaning and preprocessing

Pandas – Data manipulation and analysis

NumPy – Numerical operations

Jupyter Notebook – Interactive coding and documentation

CSV – Input and output data format
